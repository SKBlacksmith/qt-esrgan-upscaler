# Contributing

This repository is the canonical upstream for ESRGAN Batch Upscaler. It is
published for public use and forking; upstream development is maintainer-only.

- Forks are welcome. You may modify and distribute your fork under the terms
  of `LICENSE`.
- Pull requests from accounts other than `SKBlacksmith` are automatically
  closed. Please keep your changes in your fork rather than opening an upstream
  pull request.
- No third-party accounts have write access to this repository. Do not request
  collaborator access.
- Bug reports and discussion are welcome through GitHub Issues. There is no
  commitment to accept a patch or provide a fix.

See the README for the project’s LLM authorship disclosure and license details.
